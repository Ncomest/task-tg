## Ручная проверка в настоящем Telegram — НЕ ЗАПУЩЕНО

Нужен Telegram-сеанс пользователя. Приложение открыть через меню
[@task_finc_bot](https://t.me/task_finc_bot), не обычной браузерной ссылкой.
Настройки BotFather менять не требуется. Агент сообщения не отправляет.

1. Открыть Mini App на телефоне. Проверить вход и повторное открытие без запроса
   повторной авторизации; выйти и заново открыть приложение для свежих initData.
2. В светлой и тёмной теме открыть команду, редактор задачи и редактор идеи.
   Проверить контраст, safe area, прокрутку с экранной клавиатурой, закрытие редактора
   и отсутствие горизонтального скролла всей страницы. Доска прокручивается отдельно.
3. В отдельной тестовой команде создать задачу, назначить участника, сменить статус,
   проверить поиск, «Мои задачи» и «Без ответственного».
4. С двух аккаунтов открыть одну задачу, сохранить разные изменения по очереди:
   второй получает конфликт, его ввод остаётся; сравнить версии и явно выбрать поля.
5. Создать идею, сохранить изменения, преобразовать в задачу. Проверить одну карточку
   на Kanban, read-only исходной идеи, просмотр связанной задачи. Удалить идею:
   задача остаётся. Удалить другую связанную задачу: повтор конверсии не создаёт новую.
6. Участник выходит/исключается: доступ закрыт, его назначения сняты. Участник
   не видит управление командой/приглашениями; администратор не может удалить команду.
7. Во время сохранения отключить сеть: текст остаётся в открытой форме, после
   восстановления связи можно повторить запрос. Проверить истечение сессии отдельно.

Сценарии с созданием и удалением выполнять только на своих тестовых данных.
Не требуется отправлять агенту initData, session cookie или bot token.
Записать модель устройства, Telegram/ОС, тему, пройденные пункты и симптомы ошибок.
