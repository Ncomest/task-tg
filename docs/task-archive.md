# Архив задач — 27.10.2026

## Реализация

Архив независим от статуса: сохраняется DONE, используются nullable archivedAt и completedAt. Обычная выдача исключает архив; GET /api/teams/:teamId/archive выдаёт архив по archivedAt DESC, id DESC с существующей cursor-пагинацией (50 записей). POST /api/teams/:teamId/tasks/:id/archive и /restore принимают { version }.

Все операции используют withTeamMember: транзакция, блокировка команды, проверка членства, поиск задачи в команде и проверка версии. Архивировать можно только DONE. Архив нельзя редактировать, удалить или отправить агенту. Завершение уже работающего агента не меняет статус архивированной задачи.

Экран архива использует существующее переключение Vue-компонентов без новой зависимости маршрутизации. В нём скрыты идеи, участники и приглашения. Архив загружается только при открытии; изменения не требуют повторного GET. Архивирование/восстановление оптимистические, с откатом, блокировкой повторного нажатия и уведомлением. Для архивирования доступна отмена. Счётчики доски вычисляются из обновлённого списка. При выборе другой команды компонент пересоздаётся; ответы старого компонента игнорируются.

## Развёртывание и ограничения

Перед запуском новой версии API применить миграцию штатной командой npm run db:deploy, затем сгенерировать Prisma Client при сборке (npm run db:generate). Миграция к рабочей БД в этой сессии не применялась.

Для ранее завершённых задач дата завершения неизвестна и отображается «Не указана»; история не подменяется датой обновления. Новые завершения через UI и агент сохраняют completedAt.

Интеграционные проверки на настоящем PostgreSQL и ручная проверка внутри Telegram НЕ ЗАПУЩЕНЫ: рабочая БД и Telegram-клиент не подключены. Новые тесты сервиса используют транзакционную заглушку, не подтверждают фактическое исполнение SQL. При ручной приёмке проверить длинные карточки на узком экране, отмену, восстановление, отключение сети и переключение команд.
